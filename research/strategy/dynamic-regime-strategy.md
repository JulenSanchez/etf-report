# 动态策略研究：区分牛熊的参数切换

> **触发词**："动态策略"、"牛熊分治"、"regime 切换"、"分市场参数"
> **关联**：REQ-395（多因子仓位控制）、REQ-396（参数切换基建）

## 动机

gam-0 是 6Y 全量最优解。牛市和熊市特征不同：牛要动量集中追涨，熊要反转分散控回撤。动态策略试图让牛熊各用各的参数。

## 结论：证伪（2026-08-04）

经过三轮独立验证，区分牛熊参数的策略被证伪：

### 证据

1. **分组 TPE（300 trial）**：10 轮交替优化，仅微调 C/band/f1_s，量级 +5.5pp。跨窗口验证发现不可复现，疑似过拟合。
2. **Sobol + TPE 全空间探索（262 trial）**：20 维均匀撒点 + TPE 精搜。**0/262 trial 跑赢 gam-0。** 最佳 trial AR=120.7%（-29pp）。
3. **手调预设 64 组**：结合市场逻辑，4~5 参数同时变动。最佳组合 +0.8pp AR 但 MDD 恶化，无 Pareto 改进。

### 根因分析

- gam-0 是事实全局最优——262 个均匀分布的 Sobol 点覆盖了整个 20 维空间，无一点优于统一参数
- 参数间跨 regime 存在复杂交互，拆开反而破坏协同效应
- 所有探索在 gam-0 邻域附近停止——远离 gam-0 的任何方向都剧烈退化
- "跨越山谷"到另一个更优点的假设未被验证——山谷的另一侧没有山峰

### 教训

- MA 趋势分牛熊 + 各用各的参数：证伪
- 统一参数（gam-0）的 6Y 全量最优：确认
- 仓位层分离（REQ-395 节后效应）：尚未探索，仍是开放方向

## 研究历史

参数分两类：

**不可切（预计算层）**：f1_ema_period、f7_window。这些在回测启动前一次性计算。如果牛熊要不同值 = 需要多份预计算 = 双倍 CPU/缓存。建议初始研究中锁定为共享值。

**可切（运行时层）**：w1/w7、f1_sensitivity、f7 全部 6 个映射参数、MH/C/CS/band。这些在主循环中，切参数 = 一行 if。零性能代价。

### 三策略及以上兼容

引擎接受 `{regime → param_dict}` 映射表，未来从 2 策略扩展到 3+ 策略无需改动架构：

```python
strategies = {
    "ma_above": {w1:82, w7:18, C:0.62, band:0.038, ...},
    "ma_below": {w1:75, w7:25, C:0.45, band:0.025, ...},
    # "crash" 未来可选
}
```

### 优化流程

```
第0轮 [ma_trend_period]              → 扫参定界（单变量）
第1~10轮 牛熊交替，各轮锁定 https://research/...
  牛 [MH,C,CS] / 熊 [MH,C,CS]
  牛 [w1,w7]   / 熊 [w1,w7]
  牛 [f1_ema,f1_s] / 熊 [f1_ema,f1_s]
  牛 [f7全组]  / 熊 [f7全组]
  牛 [band]    / 熊 [band]
最后回马枪微调
```
