# REQ-396: 回测引擎参数切换基建

**优先级**: 🟡 P1 | **状态**: discussing | **目标版本**: v3.16.0 | **依赖**: 无 | **创建日期**: 2026-07-31

## 动机

动态策略（`research/strategy/dynamic-regime-strategy.md`）需要回测引擎支持根据 regime 自动切换参数。当前引擎只接受单一 `config_override`，无法在不同市场状态下使用不同参数组。

## 技术方案

### 核心改动

`run_backtest` 新增参数 `strategies: dict = None`：

```python
strategies = {
    "ma_above": {"w1": 82, "w7": 18, "C": 0.62, "MH": 2, "band": 0.038, ...},
    "ma_below": {"w1": 75, "w7": 25, "C": 0.45, "MH": 4, "band": 0.025, ...},
}
```

当 `strategies` 为 `None` 时，行为与当前完全一致（向后兼容）。不为 `None` 时，每个调仓日根据当前 regime 从 `strategies` 中选择对应参数组。

### 切换参数清单

| 参数 | 可切换 | 说明 |
|------|--------|------|
| w1, w7, f1_sensitivity | ✅ | 主循环中 |
| f7_up_power, f7_up_span, f7_down_power, f7_down_span | ✅ | 主循环中 |
| MH, C, CS, band | ✅ | 主循环中 |
| f1_ema_period, f7_window | ⚠️ | 预计算参数，切换需要双份预计算 |
| ma_trend_period, ma_direction_confirm | ❌ | regime 判定本身，不能切换 |
| signal_steps, top_boost | 🔒 | 已锁定，不切换 |
| bull_pos, bear_pos | ❌ | confidence 层，是否切换待定 |

### 不改的范围

- 因子预计算逻辑不变（f1_ema_period 和 f7_window 初始锁定为共享值）
- Tuner 前端继续使用单一 preset——基建只改动 `run_backtest` 和 `BacktestRunner.run_raw`
- `research_utils.optimize_group` 暂时不动（未来可为动态策略增加 `optimize_dual`）

### 性能

零回归风险。当 `strategies=None` 时，代码路径与当前完全一致。当 `strategies≠None` 时，每个调仓日增加一次 dict 查找 + 若干 if-else 分支，总代价 < 1ms/日，6Y 回测额外开销可忽略。

## 前端

先不动。只在后端实现——研究跑出有效结果后再考虑前端怎么设计（可能是牛/熊两列参数面板，或 regime 预设体系）。

## 验证

1. `strategies=None` 时 gam-0 回测结果与当前完全一致
2. `strategies` 中所有 regime 使用相同参数时，结果与单一 preset 一致
3. `strategies` 中牛熊参数不同时，持仓和 NAV 与手算一致

## 产出

- `scripts/quant_backtest.py::run_backtest` 改动
- `scripts/research_utils.py::BacktestRunner.run_raw` 适配
