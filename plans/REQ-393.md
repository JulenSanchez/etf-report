# REQ-393: F8 成交量因子重设计 → F3 退役

**优先级**: 🟡 P1 | **状态**: closed | **关闭日期**: 2026-07-30

## 缘起

F3（方向性成交量比）截面区分力极弱：支配度 9%，856 天中 0 天主导，得分全在 [50.3, 52.6]。用户盘感驱动发起 F8 成交量因子重设计。

## 研究过程

### Phase 1: 事实确认
- 588010 放量 6.8x +32.8% → 成交量信息真实存在
- 全池截面 r=0.009 → 纯放量不区分方向
- 信号必须签名方向：放量上涨 ≠ 放量下跌

### Phase 2: 全池 6Y 特征探索
- 成交量突破 + 涨 → fwd20d +1.76%
- 缩量下跌 → 均值回归 +2.83%
- 板块差异巨大：科技放量 +4.36%，传统板块无意义

### Phase 3: F8 因子回测
- F8c AMFI（sigmoid）：AR=122.6%，-16.6pp vs gam-0
- F8a VBS（全部版本）：全败（15~109%）
- 结论：成交量是稀疏事件型信号，在连续加权排名框架中结构性地无法发挥作用

### Phase 4: F3 空白对照实验（2026-07-30）
- 三组回测 + band 缩放等价性分析
- **F3 信号价值 ≈ 0**：真实 F3 vs 空白常数 50，AR 差 0.13pp
- **F3 权重稀释价值 ≈ 24pp**：空白 F3 占 20% 权重 vs 删 F3，AR 差 24pp
- **根因不是分散化，是得分尺度**：F3×20%=10 分基底让综合分 σ 变小，band/σ 变大，替换门槛升高

### Phase 5: F3 退役，base_score 接替
- gam-0 改造为 82/18 两因子 + base_score=10 + band=0.038
- AR 从 281.6% 提升至 291.6%（+10pp），MDD 持平
- `base_score` 参数化得分基底厚度，不再需要通过 F3 权重间接控制

## 结论

**成交量数据正式退出日频排名框架。** F3 退役不是否定成交量的价值——588010 案例证明放量信息真实且强——是否定"日频线性排名"这个使用方式。成交量将以仓位放大器、调仓触发器、风险过滤器等形式召回。
